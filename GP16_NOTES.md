# Roland GP-16 mode - prep notes (2026-09-30)

Source: owner's manual OCR (archive.org manual_GP16_OM_ROLAND_EN), saved here as gp16_owners_manual_ocr.txt
(MIDI chart ~line 13624, exclusive spec ~12415-13560). OCR is messy: verify tables against page scans
(manualslib.com/manual/603494/Roland-Gp-16.html). Service notes (archive.org roland_GP-16_SERVICE_NOTES) are
hardware only (test mode, boards) - the MIDI data is in the OWNER's manual, not the service manual.

## Confirmed from the chart
- Basic channel 1-16, rx + tx, stored in memory. No notes, bend, clock etc.
- Program Change rx+tx, 0-127 (A1-1..B8-8 = 128 patches). Panel patch change transmits PC.
- CC rx: 7 = volume (needs System Mode 9 MIDI FILTER = RECEIVE), 16 = GP controller 1 (expression pedal
  value -> the assigned parameter, EXPRESSION DEVICE must be PEDAL), 80 = GP ctrl 5 (<64 off, >=64 on:
  output MUTE or BYPASS per System Mode 10 CONTROL PEDAL). CC16 also re-output as 0-31/64-95 (note *3).
- Sysex rx+tx. Format: F0 41 <dev=ch-1> 2A <cmd> <addr MSB,mid,LSB> ... [size or data] <sum> F7
  mfr 41h (Roland), model 2Ah, RQ1=11h (addr + 3-byte size), DT1=12h (addr + data + checksum, checksum ignored on rx).
  GP-16 never transmits RQ1. Example in manual: F0 41 00 2A 11 0? 40 63 00 00 01 5B F7 (read 1 byte, offset 63h OUTPUT CHANNEL).

## Address map (7-bit hex) - first byte selects area
- 00 xx 00 non-verifiable TEMPORARY buffer (the edit buffer; live editing goes here), 04 xx 00 verifiable temp.
- 01..  internal patches by number A1-1..B8-8 (bytes: 01=A-1-1..B-8-8 non-verif, 09.. verifiable); 03 bank,
  05 group, 07 all. Patch N block = 128-byte-stride (mid byte = patch 0-127, LSB = offset in patch).
  (Reconcile exact bytes against page scan before coding.)
- Per-patch offsets (LSB), approx from OCR:
  00-0B joint data (effect ORDER of the 12 blocks; values 0-4 at 00-04, 6-16 at 05-0A, no repeats)
  0C mode select (chorus/flanger, pitch shifter/space-d) + distortion/overdrive
  0D effect on/off bits (blocks A1-A6, B1-B6)
  0E COMP tone/attack/sustain/level... then DIST, OD, TURBO, PICKING FILTER, STEP, PARAMETRIC EQ, NOISE SUPPR,
  SHORT DELAY, CHORUS, FLANGER, PITCH SHIFTER, PANPOT/TREMOLO, TAP DELAY, SPACE-D, LINE-OUT FILTER,
  REVERB, MASTER VOL (5C), EXPRESSION ASSIGN (5C?) / DEVICE / LFO RATE / MAX/MIN (MSB+LSB), OUTPUT CHANNEL 63h,
  PATCH NAME 64h-73h (16 ASCII), END OF NAME 74h (fixed), SOUND CHANGE REQUEST 75h.
  => ~0x76 bytes/patch. Exact offsets/ranges for every param: TABLE in manual p72-74 (need page image).
- SOUND CHANGE REQUEST (offset 75h): send after editing buffer data so the GP-16 applies it (else it only
  applies when you manually enter Edit mode). Manual example of bypass: two DT1 messages (see OCR ~line 13000).

## OS-modding hardware facts (service notes, 2026-10-10; full OCR in gp16_service_notes_ocr.txt)
- CPU IC16 (Main): NEC uPD70320GJ-8 = V25-class (V20/8086 family core, on-chip periph), 8 MHz.
- Program ROM IC11 (Main): TC531001CP 1Mbit (128 KB) MASK ROM (Roland label R15179985-1 = v1.02) OR TC541000 1Mbit OTP,
  "electrically compatible" -> an OTP/27C010-style swap is the intended repair path. Ver 1.00 -> 1.02 exist (minor rev = ROM swap).
- S-RAM IC12 M5M5256BP-12LL 32 KB (patch memory, battery backed). D-RAM IC21-26 M5M4464P-12 (6x64Kx4, DSP delay memory).
- DSP: 3x TC23SC260AF (IC17-19) + gate arrays TC17G005 (IC13), M60014 (IC10). Digital filter SM5807EP IC8.
- Audio: 16-bit 64x oversampling MASH A/D (IC12 Analog board), 16-bit 4x D/A; 24-bit internal DSP. Dated Jan 1990.
- Test mode: hold FUNCTION down + WRITE + BANK(VALUE down) while powering on, enter ID 5,2,1,8. Test mode can bulk dump/verify (save user data first).
- Version check: test mode "4. D-RAM BUS check" display shows ROM version.
- Not found anywhere: ROM dump, disassembly, firmware mods. Next: pull ROM IC11 (mask => read with 27C010 adapter; chip is 32-pin DIP), load in Ghidra as NEC V25/V20 (x86 real mode, 16-bit).

## Deep research round 2 (2026-10-12)
- IC10 M60014 is labelled **BOSS-017** on the block diagram (Boss custom gate array, DSP host interface/glue). User spotted this.
- Block diagram: V25 (IC16) -> DSP ADDRESS BUS A0-A4 + DSP DATA BUS D0-D7 -> M60014 BOSS-017 (IC10) -> 3x TC23SC260-002
  (IC17-19 = CHIP 0/1/2), 49.152 MHz clock, TC17G005 (IC13) + D-RAMs, SM5807 filter. EOS + Busy lines back to the CPU.
  Narrow 5-bit register-port interface => DSP code/coeffs are most likely pushed by the CPU from IC11 at boot (unconfirmed).
- Boot banner is "Super GP Ver 1.0"; boot error "M60014 or DSP can't open" (early units, fixed by SUB board / IC13 rework).
- DSP chip TC23SC260AF-002 (Toshiba 1989, designer Naoya Nozawa) is in: RSP-550, JD-800, GP-16, SE-50, ME-10.
  RE project: github.com/giulioz/roland-dsps (mirror ToddAWalter/roland-dsps). Its dsp/ page for THIS chip is EMPTY so far;
  the later CSP chip (same designer) is documented: host-loaded PRAM/CRAM (program + coefficient RAM), DRAM interface,
  algos extracted from host ROMs. Expect the TC23SC260 to work similarly.
- Sister units with the same DSP: SE-50 (CPU HD63B03YF, ROM LH530886, 28 algos), RSP-550 (v1.04 OS binaries posted on
  Gearspace "Roland RSP-550? Any thoughts?" thread, 2 EPROMs A/B), JD-800 (MAME driver, preliminary). If algos are host-loaded,
  these ROMs hold more TC23SC260 programs => possible algo transplant into GP-16 (needs I/O/DRAM layout match).
- Chain limit: Block A (5 movable + Noise Supp fixed) -> Block B (5 movable + Line-out Filter fixed); effects cannot cross
  blocks (users note "delay before distortion impossible"). Likely DSP-allocation limit = interesting mod target.
- No GP-16 ROM dump, MAME driver, Ghidra V25 module, or existing mod found anywhere. Ghidra: use x86 16-bit real mode,
  add V25 SFRs by hand (internal data area, IDB register; NEC V25/V35 hardware user's manual on Renesas).
- Editors that exist: Midi Quest GP-16 editor/librarian, old "GP16 MASTER" freeware.

## DUMPED 2026-10-12 - unit 1 IC11
- dumps/gp16_u1_ic11.bin, 128 KB, read 2x identical, MD5 ac5f56bcb3d8c30ddf3f1ffe88b13556.
  minipro 0.7.4 (Desktop/rosetta_rom/tools/minipro_win), `-p AM27C010@DIP32 -y -r`, chip ID 0x9886 (ignored). Close XGpro first.
- ROM maps at E0000-FFFFF. Reset vector @1FFF0 = EA 88 00 3B E8 = JMP E83B:0088 -> ROM offset 0x8438 (entry point).
- 0x0000: factory preset patches (starts with joint data 00..0B); names e.g. "HyperBassEV-5AMP" @0xA2D.
- Strings: error/verify @0x1A2BF+, "M60014 or DSP / Can't Open" @0x1A65E, test mode @0x1BF58, param names @0x1EF71+,
  "L.O.FIL-PRESENCE/TREBLE/MIDDLE/BASS" @0x1F4F9-0x1F543, block names ("PICKING FILTER" @0x1F590, "LINEOUT FILTER" @0x1F618),
  "Super GP Ver 1.0" @0x1F682.
- Hidden credits + demo @0x1BAC7: "Super GP DEMO", N.Nozawa (DSP LSI), Y.Sakai (algorithms), N.Ishizu, S.Inoue,
  Paul Youngblood (GP-8/GP-16 presets), Jimmy Yamada. Init menu: 1 Factory Preset one-patch load, 2 all-patch load,
  3 System init, 4 English demo, 5 Japanese demo.
- FREE SPACE IS TIGHT: only ~4.2 KB in runs >=256 B (0x065EC 912B, 0x06D64 912B, 0x19C00 1 KB FF, 0x1B93B 393B, 0x1FBBE 1 KB).
  Options for big mods: reclaim the demo/credit text (~1 KB), or bank-switch an SST39SF040 (A17/A18 from a spare V25 port pin)
  to get 3 more 128 KB banks.
